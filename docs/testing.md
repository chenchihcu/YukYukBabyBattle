# 自動化測試與 QA 驗證規範 (Testing & QA Guide)

本規範訂定《禹旭寶貝大作戰》之自動化關卡測試機制、手動 QA 測試點檢項目與效能退化 (Regression) 防禦標準。

---

## 🤖 1. 自動化關卡驗證 (`test_200_stages.js`)

專案包含 [test_200_stages.js](file:///c:/Users/user/Documents/坦克大戰/test_200_stages.js) 自動化校驗腳本，可在不安裝瀏覽器環境下直接以 Node.js 驗證 1 到 200 關卡地圖生成的完整度與安全性。

### 執行測試
```bash
node test_200_stages.js
```

### 驗證指標
1. **地圖矩陣維度**：確保每一關皆為 `13 × 13` 地形陣列與 `26 × 26` SubMap 陣列。
2. **出生點安全 (Spawn Point Safety)**：
   - 玩家出生點 (`Row 24, Col 8` & `Row 24, Col 16`) 必須為可通行空地 (TILE.EMPTY)。
   - 鷹徽基地 (`Row 24, Col 12`) 必須完整放置。
   - 敵軍三大出生點 (`Col 0, 12, 24`) 不得為全封閉鋼牆。

## ⚡ 3. 效能與幀率基準測試 (Performance Benchmark)

1. **幀率目標**：在 1080p 解析度及 Chrome 瀏覽器下保持穩定 **60 FPS**。
2. **記憶體洩漏防禦**：
   - 粒子池 (Particle Pool) 數量上限設為 300，超過上限自動 recycle。
   - Web Audio 音效節點 (AudioNode) 播送完成後必須呼叫 `.disconnect()` 釋放。
3. **頁面標籤頁節能 (Visibility Standard)**：切換至後台頁面時自動暫停 BGM 播送與動畫循環。
